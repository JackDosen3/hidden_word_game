# 🎲 《데블스 플랜 3》 히든 워드 (Hidden Word) 멀티플레이어 게임

팀원들이 **초대 링크(`/?room=방코드`)**로 실시간 입장하여 함께 즐길 수 있는 《데블스 플랜 3》 '히든 워드' 웹 애플리케이션입니다.

## ✨ 주요 기능

1. **🔗 원클릭 초대 링크 멀티플레이어 (WebSocket 실시간 연동)**
   - 상단 `[🔗 초대 링크 복사]` 버튼을 누르면 `http://<IP>:8080/?room=XXXXX` 링크가 복사됩니다.
   - 팀원이 링크를 클릭하면 방 코드가 자동 입력되어 닉네임만 적고 즉시 같은 방에 합류합니다.

2. **⚖️ 공식 AI 유사도 채점 심판 포맷**
   - `[정답 단어]`와 `[플레이어가 제시한 단어/힌트]`를 비교하여 항상 아래 형식으로 간결하게 판정합니다:
     ```text
     - 정답 여부: (일치 / 불일치)
     - 유사도: (0~100점 사이 정수)
     ```
   - 상단 `[⚖️ 1:1 심판 채점기]` 모달에서도 언제든 직접 `[정답 단어]`와 `[제시 단어/힌트]`를 넣어 심판 응답을 테스트할 수 있습니다.

3. **💡 유사도 90점 이상 달성 시까지 연속 힌트 자동 제공**
   - 플레이어가 단어를 제시했을 때 아직 최고 유사도가 **90점 미만**이면, **유사도 90점 이상이 나올 때까지 매 시도마다 AI가 단계별 추가 힌트를 자동으로 제공**합니다.
   - 필요할 때 `[✨ AI 다음 단계 힌트 즉시 받기]` 버튼으로 추가 힌트를 즉시 열어볼 수도 있습니다.

4. **🎮 두 가지 게임 모드 지원**
   - **🤖 AI 출제 협동 모드**: AI가 히든 워드를 선정하고 모든 팀원이 함께 추리
   - **🧑‍⚖️ 팀원 직접 출제 모드**: 팀원 중 1명이 출제자가 되어 `[정답 단어]`를 직접 입력하고 힌트를 제시하며 진행

## 🚀 실행 방법

```bash
cd /Users/bongbong/workspace/hidden_word_game
./run.sh
```

브라우저에서 `http://localhost:8080` 으로 접속하세요!
(외부 네트워크의 팀원에게 초대 링크를 공유하려면 `ngrok http 8080` 또는 `cloudflared tunnel --url http://localhost:8080` 주소를 사용할 수 있습니다.)
